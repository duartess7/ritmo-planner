# Ritmo Planner

PWA de tarefas feito em HTML, CSS e JavaScript puro. Funciona offline, salva tudo no aparelho e pode ser instalado na tela inicial do iPhone.

## Executar localmente

Use qualquer servidor estático. O Service Worker exige HTTP ou HTTPS:

```bash
npx serve .
```

## Instalar no iPhone

Abra o endereço no Safari, toque em Compartilhar e escolha **Adicionar à Tela de Início**.
